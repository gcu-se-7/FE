# 🍲 한식 레시피 추천 프론트엔드 (sunwoo 브랜치)

React 기반의 한식 레시피 소개 및 추천 웹앱입니다.

## 📌 주요 기능

### ✅ 1. 메인 페이지 (`/`)
- 재료를 입력하고 난이도(쉬움/보통/어려움)를 선택하면
- 해당 조건에 맞는 레시피 목록을 추천
- 레시피에는 이미지, 이름, 난이도, 사용된 재료가 표시됨

### ✅ 2. 인트로 페이지 (`/intro`)
- 음식 이름(예: 김치찌개, 갈비찜 등)을 검색하면
  - 음식 소개글
  - 대표 이미지
  - 주요 재료 목록
- 카드 스타일로 깔끔하게 구성됨

---

## 📁 파일 구성

| 파일 / 디렉토리 | 설명 |
|------------------|------|
| `src/pages/Home.js` | 메인 추천 기능 (재료 입력 기반) |
| `src/pages/Intro.js` | 음식 이름 검색 중심의 인트로 기능 |
| `src/components/IntroRecipeList.js` | 인트로용 카드 리스트 컴포넌트 |
| `src/App.js` | 라우팅 설정 포함 (`/`, `/intro`) |
